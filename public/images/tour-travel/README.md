# Tour & Travel Images

Please place your tour and travel images in this directory with the following names:

1. `tour-01.jpg` - Burj Al Arab and Jumeirah Beach, Dubai
2. `tour-02.jpg` - Dubai skyline at dusk with Burj Khalifa
3. `tour-03.jpg` - Dubai city skyline with Burj Khalifa
4. `tour-04.jpg` - Atlantis, The Palm resort on Palm Jumeirah, Dubai
5. `tour-05.jpg` - Ain Dubai Ferris wheel and city skyline, Dubai
6. `tour-06.jpg` - Dubai port with cruise ships and city skyline

**Image Requirements:**
- Format: JPG, PNG, or WebP
- Recommended size: 1200x800 pixels or larger
- File size: Optimize images to keep file sizes reasonable (under 500KB each recommended)

Once you add the images, they will automatically appear in the Photo Gallery section of the Tour & Travel service detail page.
